# News Feed Simulator

## Deskripsi

News Feed Simulator merupakan proyek tugas praktikum Pengembangan Aplikasi Mobile yang dibuat menggunakan Kotlin.

Project ini mensimulasikan data berita yang masuk secara berkala menggunakan Kotlin Flow, memfilter berita berdasarkan kategori Teknologi, mengambil detail berita menggunakan Coroutines, dan menghitung jumlah berita yang telah dibaca menggunakan StateFlow.

## Cara Menjalankan

1. Clone repository:
git clone https://github.com/R1ngG3r1/TugasPAM.git
2. Buka repository TugasPAM menggunakan Android Studio.
3. Buka project yang berada di folder Minggu2.
4. Tunggu proses Gradle Sync sampai selesai.
5. Pilih konfigurasi desktopApp / AndroidApp.
6. Klik Run untuk menjalankan program.
